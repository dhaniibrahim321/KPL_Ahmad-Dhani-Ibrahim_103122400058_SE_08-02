## Penyelesaian
Pertama, saya buat sebuah function hitung dengan parameter str(untuk input text) dan mode(untuk penentu jenis perhitungan). di dalam function tsb saya memasukkan potongan kode dari soal untuk menghitung jumlah seluruh karakter tanpa menghitung spasi menggunakan for loop.
```js

let jumlahSemua = 0;

    for (const c of str) {
        jumlahSemua++;
    }

    let jumlahHuruf = 0;
    for (const c of str) {
        if (c === ' ') continue;
        jumlahHuruf++;
    }
```
Supaya hasilnya dapat digunakan diluar fungsi, maka saya menambahkan conditional dimana:
* Jika mode yang dimasukkan adalah "semua" maka fungsi akan mengembalikan nilai dari jumlahSemua
* Jika mode yang dimasukkan adalah "huruf" maka fungsi akan mengembalikan nilai dari jumlahHuruf
```js
 if (mode == "semua") {
        return jumlahSemua;
    } else if (mode == "huruf") {
        return jumlahHuruf;
    }
```
