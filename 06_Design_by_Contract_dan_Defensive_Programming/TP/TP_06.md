Diberikan dua kode yang sama-sama melakukan operasi pembagian. Pertama menggunakan asersi, kedua menggunakan eksepsi.
```js
const assert = require('assert');

function divide(a, b) {
  assert(typeof a === 'number' && typeof b === 'number', 'Nilai harus bilangan bulat');

  assert(b !== 0, 'Tidak bisa pembagian dengan nol');

  return a / b;
}
```

```js
function divide(a, b) {
  if (typeof a !== "number" || typeof b !== "number") {
    throw new TypeError("Nilai harus bilangan bulat");
  }

  if (b === 0) {
    throw new Error("Tidak bisa pembagian dengan nol");
  }

  return a / b;
}


try {
  const result = divide(10, 2);
  console.log("Hasilnya adalah:", result);
} catch (error) {
  console.error("Error:", error);
}
```
Menurutmu, kapankah kita saatnya menggunakan asersi atau eksepsi untuk fungsi seperti ini di atas? Apakah kita harus sepenuhnya asersi, atau sepenuhnya eksepsi? Lakukan riset dan berikan jawabannya dalam bentuk esai minimal 300 kata.

## JAWABAN
Penggunaan asersi pada fungsi di atas paling tepat dipakai saat fase pengembangan buat memastikan integritass logika internal, seperti menjamin bahwa antar komponen kode saling mengirimkan tipe data yang benar sesuai yang disepakati, jadi fungsinya untuk memastikan logika kode kita tuh udah bener saat fase pengembangan. 

Sebaliknya, eksepsi wajib dipakai untuk menangani kondisi yang muncul ketika aplikasi sudah berjalan dan digunakan oleh user, seperti ketika user secara tidak sengaja memasukkan angka nol sebagai pembagi, kita kan gamau dong aplikasinya tbtb force close atau ke logout sendiiri. Maka fungsi exepsi disini tuh biar program bisa menangkap eror lwt try-catch dan nampilin pesan eror ke user.

Lalu, harus sepenuhnya asersi atau ekspsi? menurutku harus keduanya, dikarenakan keduanya memiliki fungsi masing" yang berbeda namun saling melengkapi dalam menjaga kualitas aplikasi. Menggunakan asersi untuk menangkap kesalahan developer (bug) saat proses perancangan/koding, sedangkan eksepsi untuk menangani kesalahan dari user (input) saat aplikasi sudah dijalankan. Dengan hibrida ini, aplikasi yang dihasilkan akan stabil, berkualitas, dan reliabel secara fungsionalnya.
