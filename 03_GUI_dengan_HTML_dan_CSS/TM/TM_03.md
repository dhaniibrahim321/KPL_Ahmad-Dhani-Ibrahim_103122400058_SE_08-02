## Soal 
Setelah kamu menyelesaikan tugas pendahuluan (bisa buka di atas), terapkanlah fungsi untuk (1) menghitung huruf kecil yang disediakan di #hk, (2) mengubah huruf kecil ke huruf besar ketika pengguna menekan tombol #huruf-besar, dan (3) mengubah huruf besar ke huruf kecil ketika pengguna menekan tombol #huruf-kecil.

Untuk nomor 2 dan 3, tampilkan hasilnya di dalam editor-kecil.

Kemudian, hapuslah fitur "Paragrafkan" dari alat.

Source code: [index.html], [index.css], [index.js]

Pertama, cari dan hapus kode tersebut dari file [index.html].
```html
    <button id="huruf-paragraf">Paragrafkan</button>
```
Agar program dapat membaca huruf kecil dan besar maka kita perlu menambahkan program pada [index.js]
Untuk pertama-tama kita tambahkan inisiasi element:
```js

const hk = document.getElementById("hk");
const hb = document.getElementById("hb");

```

lalu tambahkan addEventListener yang berfungsi untuk mendeteksi setiap perubahan input yang dilakukan oleh si user setiap mengetik/menghapus.
```js
editorElement.addEventListener("input", (event) =>{
    const textLength = event.target.value;
    const totalHuruf = (textLength.match(/[a-zA-Z]/g) || []).length;
    const hurufBesar = (textLength.match(/[A-Z]/g) || []).length;
    const hurufKecil = (textLength.match(/[a-z]/g) || []).length;

    charCountElement.textContent = totalHuruf;
    hb.textContent = hurufBesar;
    hk.textContent = hurufKecil; 
});
```
Function tersebut berfungsi untukk mengambil inputan yg terdapat di textarea, lalu menghitung jumlah seluruh huruf, dan digunakan untuk menghitung huruf besar maupun kecil saja

```js
const btnBesar = document.getElementById("huruf-besar");
const btnKecil = document.getElementById("huruf-kecil");

btnBesar.addEventListener ("click", () => {
    editorElement.value = editorElement.value.toUpperCase();
    editorElement.dispatchEvent(new Event("input"));
});

btnKecil.addEventListener ("click", ()=> {
    editorElement.value = editorElement.value.toLowerCase();
    editorElement.dispatchEvent(new Event("input"));
});
```
