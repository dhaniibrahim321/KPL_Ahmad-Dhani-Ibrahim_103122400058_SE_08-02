## Soal
Dari dua kode di bawah ini, mana yang kamu ingin cari masalahnya dan perbaiki di tengah-tengah malam, katakanlah jam 1 malam? Mengapa?
```js
function processUser(user) {
  if (user) {
    if (user.isActive) {
      if (user.hasPermission) {
        return doSomething(user)
      }
    }
  }
  return null
}
```
```js
function processUser(user) {
  if (!isValidCandidate(user)) return null;
  return doSomething(user);
}

function isValidCandidate(user) {
  return user && user.isActive && user.hasPermission;
```

## Deskripsi
Saya akan memilih kode kedua karena menurut saya lebih sederhana, mudah dibaca, dan mudah dipelihara. Jadi ketika saya mengalami situasi seperti debugging atau maintenance di tengah malam, kode yang memiliki struktur jelas, sedikit nesting, dan pemisahan tanggung jawab yang baik akan jauh lebih mudah dipahami dibandingkan kode yang menggunakan banyak kondisi bersarang. Ini sejalan dengan prinsip clean code yang mengutamakan keterbacaan (readability) dan kemudahan pemeliharaan (maintainability).
