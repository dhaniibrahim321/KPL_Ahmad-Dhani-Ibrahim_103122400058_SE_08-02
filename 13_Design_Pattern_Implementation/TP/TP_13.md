## Implementasi kode
```ts
const dbConfig = {
  host:            process.env.DB_HOST     || "localhost",
  port:            Number(process.env.DB_PORT) || 3306,
  user:            process.env.DB_USER     || "root",
  password:        process.env.DB_PASSWORD || "",
  database:        process.env.DB_NAME     || "perpustakaan_db",
  connectionLimit: 10,
};

const pool = mysql.createPool(dbConfig);

export default pool;
```
## Deskripsi
Jadi,kode di atas merupakan Singleton karena memanfaatkan mekanisme module caching pada Node.js untuk memastikan fungsi mysql.createPool hanya dieksekusi satu kali selama siklus hidup sistem. Dengan menyimpan objek koneksi tunggal (pool) tersebut ke dalam memori dan membagikannya secara global ke seluruh modul yang melakukan import, pendekatan ini menjamin bahwa tidak terjadi duplikasi koneksi yang tidak efisien. Selain menghemat penggunaan memori, pola ini menjaga stabilitas sistem dengan memastikan bahwa seluruh modul mengakses sumber daya database secara konsisten, terpusat, dan tetap berada dalam batasan connectionLimit yang telah ditentukan.
